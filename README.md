# 召唤之夜 3 PSP 中文版 · 问题反馈

本仓库用于提交翻译问题、核查中日翻译对照。

## 提交问题

先在 [Issues](https://github.com/yangtuojiang/SN3zhCN_bugreport/issues) 搜索台词或关键词，看看是否已有相同反馈；有的话在原问题下补充即可。

新问题请附上**游戏截图**，注明版本、章节或所在界面，并说明哪里不对、为什么觉得不对。有建议改法也可以一起写。显示异常或无法操作的问题，请补充复现步骤、设备和模拟器版本。尽量一条 Issue 对应一个问题。

## 翻译对照

[下载翻译对照 CSV](https://github.com/yangtuojiang/SN3zhCN_bugreport/raw/refs/heads/main/翻译对照.csv)（v1.3，UTF-8）。包含已登记的剧情、战斗对白、系统文本和名称；不含图片内文字。

- 每行对应一个文本槽；按“文本组”和“组内行号”连读对白，“对应主槽”用于关联物理副本。
- “原版槽位字节上限”与 v1.3 的“槽位字节上限”均不含结尾零字节；“双字节字符上限”按每字 2 字节计算，不是所有语言都适用的字符数。原始／当前偏移是资源内偏移，不是 ISO 绝对地址。
- “显示列上限”与存储容量分别计算，未确认的值留空。姓名变量 `▲`、`●` 本身占 2 字节，展开后的名字另计显示宽度；保留变量及控制码。
- 翻译其他语言时还需核对编码、字库、实际字宽和分行，不能仅凭 CSV 改字后直接写回。

非官方汉化，仅供交流，严禁商用，请支持正版。
