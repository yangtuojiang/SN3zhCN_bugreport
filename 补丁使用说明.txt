Public Release 1.0 → 1.0.1 累计更新补丁

一、本次更新

1. 修正部分文案问题。
2. 修正学生姓名后出现多余空白的问题

二、使用前准备

本补丁只适用于 Public Release 1.0 正式完整包中的 ISO。
它不适用于日文原版、早期测试包、其他汉化版或已经打过更新补丁的镜像。

请保留一份未经修改的 Public Release 1.0 ISO。
后续更新也会提供“Public Release 1.0 → 最新版”的累计补丁：
每次用这份 1.0 原镜像打最新补丁即可，无须依次安装旧补丁。

正确的 1.0 原镜像：
常用文件名：SN3_zhCN_public_release_1.0.iso
文件大小：1,710,286,848 字节
SHA-256：8e8b3dc9181b9c1b9f0bd1c87f1f60753c856ef66d159d548b11bc18973e9a46

文件改名不影响使用，文件内容必须一致。文件名相同并不代表版本相同。
请先把完整包和补丁包解压，不要直接选择 ZIP，也不要选择 CSO。

三、Windows 电脑操作

适用于 Windows 10/11 64 位。包内已附便携版 xdelta3，无须另装补丁软件。

1. 将整个补丁包解压到一个普通文件夹。不要只取出其中的 BAT 文件。
2. 双击“Windows_打补丁.bat”，在弹出的窗口中选择 Public Release 1.0 的 ISO。
   也可以将 ISO 拖到这个 BAT 文件上。
3. 程序会先核对原镜像及补丁文件，再生成新版 ISO，最后核对生成结果。
   原镜像不会被覆盖。请为新版 ISO 预留至少 2 GB 空间。
4. 看到“更新成功”后，在 PPSSPP 中打开新生成的：
   SN3_zhCN_public_release_1.0.1.iso

默认将新版 ISO 放在原镜像旁边。如果该目录不能写入，请先把原镜像复制到
自己可读写的文件夹后重试。无需以管理员身份运行。

四、安卓手机操作

包内附有 UniPatcher 0.19 官方安装包，要求 Android 7.0 或以上。
已经安装兼容版本的 UniPatcher，可以直接使用，不必重复安装。

1. 将补丁包完整解压，并准备好 Public Release 1.0 的 ISO。
   建议放在“Download/下载”中的普通文件夹，避免选择 Android/data 等受限目录。
2. 安装 tools/android/UniPatcher-0.19.apk。
   如果系统提示安装权限，只为本次使用的文件管理器允许安装即可。
3. 打开 UniPatcher 的“应用补丁”页面，依次选择：
   补丁文件：SN3_Public1.0_to_1.0.1.xdelta
   ROM 文件：Public Release 1.0 的 ISO
   输出文件：新建 SN3_zhCN_public_release_1.0.1.iso
4. 保持“无视校验和”关闭，开始应用补丁并等待完成。
   处理期间不要关闭应用。建议预留至少 6 GB 空间，供临时文件和新版 ISO 使用。
5. 完成后，在 PPSSPP 中选择新生成的 ISO。

如果手机安装或文件选择受系统限制，可以先在电脑上完成第三节的操作，
再将生成的新版 ISO 复制到手机，无须在手机上再次打补丁。

五、存档与常见问题

更新后请重新启动游戏，从游戏内“读取”加载普通存档。
本补丁不会修改 PSP/SAVEDATA 中的存档文件，不需要重新开始游戏。
不要用旧的 PPSSPP 即时存档继续测试新版；即时存档可能保留旧程序和旧文本。

提示原镜像不匹配或校验错误：
确认选中的是未修改的 Public Release 1.0 ISO，而不是压缩包、CSO、测试版，
也不是已经更新过的 ISO。不要强制跳过校验。

提示无法打开文件或写入失败：
确认补丁包已经完整解压，所选目录允许读写，且剩余空间足够。
安卓可将文件移到 Download/下载中的普通文件夹后重新选择。

已安装上一个更新版本，还需要重新打旧补丁吗？
不需要。使用保留的 Public Release 1.0 原镜像和最新累计补丁，直接生成最新版。

新版仍显示旧文字：
先确认 PPSSPP 打开的是新生成的 ISO，并彻底退出游戏后从普通存档读取。
如果仍有问题，请提交截图、版本、所在章节或界面及复现步骤。
