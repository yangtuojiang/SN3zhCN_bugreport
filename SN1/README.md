对应 **Public Release 1.0 / SN1_ZHCN_1_0**。语音增强版与 `SN1_ZHCN_1_0_Pure` 纯汉化版使用相同译文。

[下载中日翻译对照 CSV](https://github.com/yangtuojiang/SN3zhCN_bugreport/raw/refs/heads/main/SN1/SN1_ZHCN_1_0_翻译对照.csv)

共 **25,071 条**，包含剧情、系统文本和结局图片文字。表格保留文本 ID、资源文件、事件函数和分支块，方便定位不同主角与伙伴的台词。相同文字的不同存储位置分别列出，不合并人物分支。

- CSV 使用 UTF-8 BOM 编码，单元格内换行对应游戏文本换行。
- 说话人栏是已有定位线索；未解析项留空，不根据文本猜测人物。
- 姓名变量和控制标记按最终有效稿保留，不是可直接显示的固定姓名。
- 排除 25 个空白原文、4 个需与原版姓名键盘配套的字符表，以及 1 条误识别成文字的 ARM 指令。
- 本表不包含全部菜单、教程等美术贴图的逐像素对照，也不是可以直接导入游戏的补丁。修改仍须核对编码、字库、换行、容量和实际显示。

本轮结局前后的文字修改已核对相关主角、伙伴的事件与分支，并从两个成品 ROM 回读全部 22,453 个剧情槽。语音增强版补上结局画面的独立语音入口；54 个图片/阶段完成原生流程诊断回放，其中 50 项语音核对实际录音并检查停声，4 项原版静默特殊结局保持无配音。诊断回放不等于从开头通关全部路线，本轮未作安卓设备复测。
